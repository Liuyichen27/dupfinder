==================================================
 dupfinder · 使用说明
==================================================

【这是什么】
dupfinder —— 把重复文件揪出来，告诉你删掉能省多少空间。
整个工具没有 --delete 参数：只出报告，不删任何文件。

【怎么装】
需要 Python 3.8 或更高版本。把压缩包解压，在解压出来的文件夹里执行：

    python -m pip install .

装好后任何目录下都能用 `dupfinder` 命令。
不想装也能直接跑：python -m dupfinder.cli …（在解压目录里）

【怎么用】
    dupfinder D:/照片 D:/备份
    dupfinder D:/照片 --min-size 1M -j 结果.json

【常用参数】
    -m, --min-size 1     小于这个体积的不看（默认 1 字节）
    --no-recursive       只看当层，不进子目录
    --skip-hidden        跳过点开头的文件
    -j, --json FILE      结果写成 JSON（- 表示打到标准输出）
    -q, --quiet          只输出汇总

【它的边界】
三级筛选（大小分桶 → 64 KB 取样 → 全文 SHA-256），理论上可能漏掉极少数
头部相同、尾部不同的超大文件；但绝不会误报，也不会删东西。

【怎么确认是新版】
每次运行会在后台看一眼 GitHub，有新版本会打一行提示（查不到就安静跳过）。
不想让它查，设环境变量 DUPFINDER_NO_UPDATE=1 即可关闭。

项目主页：https://github.com/Liuyichen27/dupfinder
